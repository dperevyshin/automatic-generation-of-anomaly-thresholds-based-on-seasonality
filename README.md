## 🎓 Тема работы
**«Автоматическая выработка порогов аномалий с учётом сезонности»**

Работа посвящена задаче обнаружения аномалий во временных рядах в условиях сезонности и изменяющейся нормы поведения. Основной фокус смещён с построения отдельного детектора на исследование двух независимых слоёв:

1. **Anomaly score generation** — способ получения меры аномальности наблюдения.
2. **Threshold calibration** — способ автоматического перевода этой меры в решение «норма / аномалия».

Такой подход позволяет отдельно исследовать вклад механизма формирования score и вклад механизма калибровки порога.

## 🧩 Исследовательская идея

Вместо повторения уже хорошо изученных схем вида `STL + residual analysis + fixed detection rule`, в работе предлагается рассматривать задачу как комбинацию двух слоёв:

### 1. Score layer
Формирование численной меры аномальности наблюдения.

Планируется исследовать как минимум два подхода:
- **Residual-based score** — score на основе остаточной компоненты после декомпозиции временного ряда;
- **Forecast-error-based score** — score на основе ошибки прогноза нормального поведения ряда.

### 2. Threshold layer
Калибровка порога, переводящего score в бинарное решение.

Планируется сравнить несколько подходов:
- **Static threshold** — фиксированный порог;
- **Rolling threshold** — порог на основе скользящей статистики или квантиля;
- **Context-aware threshold** — порог с учётом контекста временного ряда;
- **Uncertainty-aware threshold** — порог на основе доверительного интервала прогноза или оценки неопределённости модели.

## 🧪 Экспериментальная постановка

В рамках работы планируется сравнение комбинаций двух типов:

### Score generators
- Residual-based score
- Forecast-error-based score

### Threshold calibrators
- Static threshold
- Rolling threshold
- Context-aware threshold
- Uncertainty-aware threshold

Таким образом, исследование строится как сравнение нескольких пар:

- residual + static
- residual + rolling
- residual + context-aware
- residual + uncertainty-aware
- forecast error + static
- forecast error + rolling
- forecast error + context-aware
- forecast error + uncertainty-aware

Отдельно результаты сравниваются с baseline-подходами из литературы.
