Репозиторий магистерской работы по задаче обнаружения аномалий в сезонных временных рядах и автоматической выработки порогов аномальности.

## Тема магистерской работы

**«Автоматическая выработка порогов аномалий с учётом сезонности»**

## Цель работы

Разработка и исследование подходов к автоматической выработке порогов аномальности для сезонных временных рядов с учётом структуры сигнала, сезонности и локальных изменений поведения ряда.

## Исследовательская постановка

В работе задача рассматривается как сочетание двух взаимосвязанных уровней:

1. `Anomaly score generation` — построение численной меры аномальности наблюдения.
2. `Threshold calibration` — перевод полученного score в решение `норма / аномалия`.

Такая постановка позволяет отдельно исследовать способы формирования сигнала аномальности и способы выбора порога, а затем сравнивать комбинации `score generator + threshold calibrator`.

## Основные задачи

- проанализировать существующие подходы к обнаружению аномалий во временных рядах;
- рассмотреть методы учёта сезонности и методы пороговой детекции;
- провести анализ сезонных временных рядов из набора NAB;
- реализовать и исследовать baseline-подходы;
- выделить информативные способы построения `anomaly score`;
- исследовать методы калибровки порога;
- провести экспериментальное сравнение комбинаций `score + threshold`;
- сформулировать итоговые выводы по результатам исследования.

## Уже выполненные разделы работы

### Обзор данных и первичный анализ

Исследованы три временных ряда из **Numenta Anomaly Benchmark (NAB)**:

- `nyc_taxi` — количество пассажиров нью-йоркских такси;
- `ambient_temperature_system_failure` — температура окружающей среды в офисе;
- `cpu_utilization_asg_misconfiguration` — загрузка CPU в AWS.

В рамках первичного анализа:

- проверена корректность временных рядов;
- подтверждено отсутствие пропусков и нарушений структуры временных отметок;
- выявлена выраженная сезонность;
- зафиксированы сезонные периоды `48`, `24` и `12` часов соответственно;
- проанализированы особенности аномальных интервалов в выбранных рядах.

### Baseline-эксперименты

Реализованы и исследованы базовые подходы:

- `Static threshold`;
- `z-score` на исходном временном ряде;
- `STL + z-score`.

Проведённое сравнение baseline-подходов используется как основа для дальнейшего расширения экспериментальной части.
