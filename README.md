# Автоматическая выработка порогов аномалий с учетом сезонности

Репозиторий магистерской работы "Автоматическая выработка порогов аномалий с учетом сезонности". Основная идея работы состоит в том, что в реальных системах мониторинга недостаточно просто получить `anomaly score`: не менее важно корректно откалибровать порог, чтобы снизить число ложных тревог при сохранении приемлемой полноты обнаружения.

В работе исследуется модульная схема `score generation + threshold calibration`, а качество сравнивается с базовыми статистическими подходами на размеченных рядах из **Numenta Anomaly Benchmark (NAB)**.

## Тема и цель работы

**Тема:** «Автоматическая выработка порогов аномалий с учётом сезонности».

**Цель:** исследовать и реализовать подходы к автоматической калибровке порогов аномальности для временных рядов с выраженной сезонной структурой, трендом и изменяющимся режимом поведения.

## Что сделано в работе

- проведён обзор литературы по обнаружению аномалий, сезонной декомпозиции, адаптивному порогированию и прогнозным подходам;
- выполнен разведочный анализ трёх сезонных рядов из NAB;
- проверено отсутствие пропусков, дублей временных отметок и нарушений порядка наблюдений;
- определены сезонные периоды для экспериментов: `48` для `nyc_taxi`, `24` для `ambient_temperature_system_failure`, `12` для `cpu_utilization_asg_misconfiguration`;
- реализованы baseline-методы:
  - статический квантильный порог;
  - `z-score` на исходном ряду;
  - `STL + z-score`;
- реализован модульный исследовательский пайплайн, где отдельно задаются:
  - способ построения `anomaly score`;
  - способ калибровки порога;
- исследованы методы построения `anomaly score`:
  - остатки `STL`;
  - ошибка прогноза `Holt-Winters`;
  - `Holt-Winters` с адаптивным переобучением;
  - `CatBoost` с адаптацией на скользящем окне;
- исследованы методы калибровки порога:
  - статический порог;
  - скользящий квантильный порог;
  - контекстно-зависимый порог;
  - порог на основе прогнозного интервала;
- проведён перебор параметров и экспериментальное сравнение методов на трёх датасетах;
- подготовлены итоговые материалы ВКР и рабочие ноутбуки с воспроизводимыми расчётами.

## Данные

В работе используются три ряда из **Numenta Anomaly Benchmark (NAB)**:

- `nyc_taxi` — количество пассажиров нью-йоркских такси;
- `ambient_temperature_system_failure` — температура окружающей среды;
- `cpu_utilization_asg_misconfiguration` — загрузка CPU.

Локальная копия датасета находится в [Data/NAB](./Data/NAB).

## Экспериментальная схема

- обучающая выборка формируется **до первого размеченного аномального интервала**;
- тестовая выборка начинается с первой аномалии и включает дальнейший участок ряда;
- это приближает эксперимент к реальному сценарию мониторинга, где модель обучается на нормальном поведении и затем применяется к будущим данным;
- дополнительно оценивается доля ложноположительных срабатываний на `train`, так как на обучающем сегменте аномалий нет.

## Метрики

Для сравнения методов используются:

- `Precision`
- `Recall`
- `F1-score`
- `F0.5-score`
- `Train FP rate`

Метрика `F0.5` вынесена в отдельный фокус, поскольку в прикладной постановке работы важно не только находить аномалии, но и снижать число ложных тревог.

## Основные результаты

По итогам экспериментов лучшие исследуемые методы превзошли baseline по `F0.5` на всех трёх рядах.

| Датасет | Лучший baseline | `F0.5` baseline | Лучший итоговый метод | `F0.5` | Прирост |
|:--|:--|--:|:--|--:|--:|
| `cpu_df` | `static` | `0.8369` | `stl_score + context_aware_threshold` | `0.9220` | `+0.0851` |
| `ambient_temp_df` | `static` | `0.4506` | `catboost_with_adaptation + rolling_quantile_threshold` | `0.8053` | `+0.3547` |
| `taxi_df` | `static` | `0.4131` | `catboost_with_adaptation + rolling_quantile_threshold` | `0.6109` | `+0.1978` |

Лучшие комбинации по датасетам:

- `cpu_df`: `precision = 0.981`, `recall = 0.744`, `F1 = 0.846`, `F0.5 = 0.922`;
- `ambient_temp_df`: `precision = 0.797`, `recall = 0.841`, `F1 = 0.818`, `F0.5 = 0.805`;
- `taxi_df`: `precision = 0.913`, `recall = 0.263`, `F1 = 0.408`, `F0.5 = 0.611`.

Итоговый вывод работы: учёт сезонности, временного контекста и адаптивной калибровки порога позволяет улучшить качество обнаружения аномалий по сравнению с простыми статистическими baseline, особенно в сценариях, где критично ограничивать ложноположительные срабатывания.

1. Установить зависимости:

